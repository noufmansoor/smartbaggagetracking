# Smart Airport Baggage Tracking System

HCT student startup prototype. We help airports and airlines track bags from check-in to baggage claim using RFID, sensors, and AI to flag handling issues and reduce misplaced luggage.

**Website:** https://noufmansoor.github.io/smartbaggagetracking/

## The problem
Bags can go missing between handoffs, and neither staff nor passengers know where a bag is until it is too late.

## How it works
- **RFID:** each bag carries a tag that is read at key checkpoints (check-in, security, loading, baggage claim).
- **Sensors and cameras:** IR sensors count bags and cameras capture photo evidence, so each read is confirmed by a second signal.
- **AI:** turns checkpoint data into clear status updates, flags bags that miss an expected update, and powers a voice assistant for passengers.

## Two dashboards
- **Staff dashboard:** flights, registered bags and checkpoint history.
- **Passenger dashboard:** sign in to follow your own bag and hear its latest status.
